# Texas Expo Tech Solutions LLC - eCommerce Shopping Portal
### Engineered for Walmart Marketplace Seller Approval

A complete, high-converting, enterprise-grade e-commerce storefront pre-configured for **Texas Expo Tech Solutions LLC**. Features 60 active products across 4 core categories, Cash on Delivery (COD) checkout, live order tracking, and all mandatory Walmart compliance policies.

---

## 🌟 Key Features

- **Store Name:** Texas Expo Tech Solutions LLC
- **4 Core Categories (60 Total Products - 15 per category):**
  1. **Clothing & Apparel (15 SKUs):** Supima cotton tees, stretch chinos, French terry hoodies, cashmere cardigans, workout leggings, trucker jackets, and more.
  2. **Home Decoration (15 SKUs):** Scandinavian ceramic vases, ambient RGB corner lamps, Moroccan rugs, floating pine shelves, canvas oil art, and scented candles.
  3. **Devices & Tech Accessories (15 SKUs):** 3-in-1 MagSafe wireless chargers, ANC Bluetooth headphones, 65W fast power banks, ergonomic stands, and USB-C hubs.
  4. **Kitchen Accessories (15 SKUs):** Japanese Damascus chef knives, precision digital scales, acacia cooking utensils, rotating spice racks, and cold brew makers.
- **Cash on Delivery (COD):** First-class payment support with doorstep collection instructions and receipts.
- **Walmart Policy Pages:** 30-Day Hassle-Free Returns, Domestic US Shipping (FedEx/UPS/USPS), Privacy Policy (CCPA), Terms of Service, About Us, and Contact Support Desk.
- **Order Tracking:** Real-time carrier shipment simulation (Order Placed &rarr; Texas Warehouse &rarr; FedEx Transit &rarr; Out for Delivery).
- **Admin Dashboard:** Access at `/admin` to monitor incoming orders, update tracking numbers, and manage store settings.

## 🚀 Quick Start (Local Run)

1. Open a terminal in this directory:
   ```bash
   cd C:\Users\USER\.gemini\antigravity\scratch\texas-expo-tech
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the application:
   ```bash
   npm start
   ```
4. Access in your browser:
   - **Storefront:** [http://localhost:3001](http://localhost:3001)
   - **Admin Console:** [http://localhost:3001/admin](http://localhost:3001/admin)

Or simply double-click **`start.bat`** on Windows!
